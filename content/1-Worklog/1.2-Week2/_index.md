### Week 2 Achievements:

* Build a solid understanding of AWS networking concepts and the role of Amazon VPC in creating secure and isolated cloud environments.

* Explore the essential components of Amazon VPC, including:

  * Virtual Private Cloud (VPC)
  * Subnets
  * Route Tables
  * Internet Gateway
  * NAT Gateway
  * VPC Endpoints

* Learn how to design and configure both Public Subnets and Private Subnets to support different networking requirements.

* Gain practical knowledge of AWS routing and network connectivity by working with:

  * Route Tables
  * Internet Gateway
  * NAT Gateway
  * Elastic Network Interface (ENI)
  * Elastic IP Address (EIP)
  
* Understand the key security mechanisms used to protect AWS networking resources, including:

  * Security Groups
  * Network Access Control Lists (NACLs)
  * VPC Flow Logs

* Study the available AWS networking connectivity solutions, including:
  
  * VPC Peering
  * AWS Transit Gateway
  * AWS Site-to-Site VPN
  * AWS Client VPN
  * AWS Direct Connect

* Compare VPC Peering and AWS Transit Gateway to understand their architectures, benefits, and appropriate use cases.

* Learn the fundamentals of Elastic Load Balancing (ELB) and its contribution to improving application availability, fault tolerance, and scalability.

* Differentiate the features and use cases of various AWS Load Balancer types:
  
  * Application Load Balancer (ALB)
  * Network Load Balancer (NLB)
  * Classic Load Balancer (CLB)
  * Gateway Load Balancer (GWLB)

* Complete hands-on exercises involving the deployment and configuration of VPCs, Subnets, Route Tables, Security Groups, Network ACLs, and Load Balancers.

* Develop the skills required to design, deploy, and manage a basic AWS networking architecture that satisfies connectivity, security, and scalability requirements.
