### Week 3 Objectives:

* Develop a solid understanding of Amazon EC2 and its core components.
* Learn how to launch, configure, and manage EC2 instances using Amazon Machine Images (AMIs).
* Explore the storage options available for EC2, including Amazon Elastic Block Store (EBS) and Instance Store, and understand their use cases.
* Gain knowledge of backup strategies, authentication mechanisms, and AWS services that support automatic scaling and high availability.

### Week 3 Achievements:

* Build a strong foundation in Amazon EC2 and understand its role in delivering scalable cloud computing services.

* Explore the essential configuration components of an EC2 instance, including:
  * CPU / GPU
  * Memory
  * Network
  * Storage

* Gain an understanding of the underlying EC2 architecture, including:

  * Hardware Nodes
  * Hypervisor
  * AWS Nitro System
  * Hardware Virtual Machine (HVM)
  * Paravirtualization (PV)

* Learn how Amazon Machine Images (AMIs) are used to provision and manage EC2 instances, with a focus on:
  
  * Root Volumes
  * Image Permissions
  * Block Device Mapping

* Understand how a single AMI can be reused to deploy multiple EC2 instances with consistent configurations.

* Explore Amazon EBS Snapshots and backup strategies to enhance data protection and disaster recovery capabilities.

* Learn secure authentication methods for accessing EC2 instances using:

  * Public Keys
  * Private Keys
  * Key Pairs

* Develop practical knowledge of Amazon Elastic Block Store (EBS), including:
  
  * SSD-based volumes
  * HDD-based volumes
  * Snapshots
  * EBS Multi-Attach

* Compare the features, advantages, and limitations of:
  
  * Amazon Elastic Block Store (EBS)
  * Instance Store

* Identify appropriate storage options based on different application requirements and workloads.
  
* Learn how EC2 User Data can be used to automate software installation and instance initialization during launch.
  
* Understand the purpose of EC2 Instance Metadata and how it provides configuration and runtime information for instances.
  
* Study the concepts of EC2 Auto Scaling, including:
  
  * Automatically scaling out when application demand increases.
  * Scaling in when demand decreases to optimize resource utilization.
  * Integrating with Elastic Load Balancing (ELB) to improve availability and traffic distribution.
  
* Broaden knowledge of related AWS services, including:
  
  * Amazon Lightsail
  * Amazon Elastic File System (EFS)
  * Amazon FSx
  * AWS Application Migration Service (AWS MGN)

* Complete hands-on exercises involving EC2 deployment, Key Pair management, and storage configuration.
  
* Develop the ability to choose suitable EC2 configurations, storage solutions, and scaling strategies to meet different 
  application and business requirements on AWS.
