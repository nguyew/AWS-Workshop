## Event Highlights

### Learning AWS Efficiently with Cost Optimization

#### Common Challenges for AWS Beginners

Mr. Huynh Thai Linh shared several common concerns that newcomers often encounter when starting with AWS:

* Worrying about unexpected AWS charges.
* Forgetting to remove cloud resources after completing labs.
* Hesitating to explore AWS services because of potential costs.
* Lacking a safe environment for hands-on experimentation.

#### Recommended Solutions

##### AWS Cloud Quest

* A free interactive learning platform developed by AWS.
* Provides hands-on labs for practicing AWS services.
* Uses game-based learning to increase engagement.
* Includes leaderboards that motivate learners through friendly competition.

##### Floci

* A local emulator for AWS services.
* Enables developers to test applications without using real AWS resources.
* Helps reduce cloud expenses during learning and development.

#### Floci vs. LocalStack

The workshop highlighted several advantages of Floci:

* Faster execution speed.
* Lower CPU, memory, and storage consumption.
* Good compatibility with AWS services.
* More flexible licensing and pricing.

However, several limitations were also mentioned:

* Only a subset of AWS services is supported.
* Some functions generate simulated responses instead of real service behavior.
* Does not fully replicate the AWS cloud environment.
* Cannot completely replace real AWS infrastructure.

### The Importance of Self-Confidence

#### Speaker

* Nguyen Thi Quynh Nhu

#### Main Discussion

This session emphasized the significance of confidence in both learning and career development.

#### The Impact of Self-Doubt

According to the speaker, lacking confidence may result in:

* Missing valuable opportunities.
* Avoiding unfamiliar challenges.
* Lower productivity in learning and work.
* Giving up easily when facing obstacles.

#### Understanding the Causes

Several common reasons for losing confidence were discussed:

* Fear of failure.
* Fear of criticism.
* Paying too much attention to results instead of personal growth.

#### The 5P Rule

The speaker introduced the **5P Rule** as a practical method for overcoming fear and gradually building confidence.

#### Benefits of Confidence

* Improves learning efficiency.
* Enhances work performance.
* Encourages long-term personal growth.
* Helps individuals seize new opportunities proactively.

#### Building Confidence in Daily Life

Several practical recommendations were shared:

* Set small and achievable goals.
* Appreciate daily accomplishments.
* Focus on continuous improvement instead of perfection.
