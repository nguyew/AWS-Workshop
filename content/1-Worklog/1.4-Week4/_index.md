### Week 4 Achievements:

* Develop a strong understanding of Amazon S3 architecture and how objects are organized within Buckets to provide scalable cloud storage.
* Explore the core features of Amazon S3, including:

  * Object Keys
  * Multipart Upload
  * Event Notifications
  * Access Points

* Gain knowledge of the various Amazon S3 Storage Classes and understand their ideal use cases:

  * S3 Standard
  * S3 Standard-Infrequent Access (Standard-IA)
  * S3 Intelligent-Tiering
  * S3 One Zone-Infrequent Access (One Zone-IA)
  * S3 Glacier
  * S3 Glacier Deep Archive

* Learn how S3 Lifecycle Policies can automate data management and optimize long-term storage costs.

* Understand the process of hosting a static website using Amazon S3.

* Explore the purpose of Cross-Origin Resource Sharing (CORS) and its role in enabling secure communication between web applications and S3 resources.

* Learn different approaches to managing access permissions for Amazon S3 resources, including:

  * Access Control Lists (ACLs)
  * Bucket Policies
  * IAM Policies

* Understand how VPC Endpoints provide secure private connectivity to Amazon S3 without requiring internet access.

* Learn how Versioning protects data by enabling recovery from accidental deletion or unintended modifications.

* Explore AWS solutions for large-scale data migration, including:

  * AWS Snowball
  * AWS Snowball Edge
  * AWS Snowmobile

* Gain an understanding of hybrid cloud storage through AWS Storage Gateway, including:

  * File Gateway
  * Volume Gateway
  * Tape Gateway

* Learn the key concepts of Disaster Recovery (DR), including:

  * Recovery Time Objective (RTO)
  * Recovery Point Objective (RPO)

Study common AWS disaster recovery strategies, including:

  * Backup & Restore
  * Pilot Light
  * Low Capacity Active
  * Full Capacity Active

* Learn how AWS Backup simplifies backup management, automation, and monitoring across AWS services.

* Successfully complete hands-on labs involving:

  * Creating and configuring Amazon S3 Buckets
  * Uploading and managing objects in Amazon S3
  * Hosting a static website on Amazon S3
  * Deploying AWS Storage Gateway
  * Creating Backup Plans
  * Monitoring and validating backup jobs

* Develop the ability to choose appropriate storage, backup, and disaster recovery solutions based on different application and business requirements within AWS environments.
