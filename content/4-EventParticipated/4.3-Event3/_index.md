## Main Topics

### AI-Powered Conversational Food Ordering

Team One introduced an AI Agent that enables customers to place food orders through messaging platforms such as Zalo and WhatsApp.

Highlights included:

* Multi-platform conversational ordering using a Channel Adapter architecture.
* Delivering a seamless ordering experience without requiring users to install additional applications.
* A processing workflow consisting of input collection, data normalization, Agent Core processing, and response generation.
* A dashboard for monitoring and managing customer conversations.
* A scalable architecture that can be extended to support additional messaging platforms and business scenarios.

### AI Agent for Enterprise Strategy Intelligence

Team Two presented an AI-powered platform designed to collect and analyze strategic business information from multiple data sources.

Key highlights:

* Automated collection of financial reports and business documents.
* Interactive dashboards for strategy management and risk analysis.
* A React-based dashboard deployed on AWS Amplify.
* AWS Lambda orchestrating multiple AI agents through Agent-to-Agent (A2A) communication.
* Amazon Bedrock managing conversation context and session memory.

### AI Application for Solution Architects

Team Three showcased an AI application developed to assist Solution Architects in designing AWS infrastructures.

The application provides:

* Converting natural language requirements into AWS architecture designs.
* Automatic generation of Draw.io architecture diagrams.
* Infrastructure cost estimation.
* Infrastructure as Code generation using CloudFormation or Terraform.
* Demonstrations of essential AI Engineering concepts such as workflow orchestration, context management, and memory handling.

### Hackathon Journey

Team 3KA shared their experiences throughout the hackathon competition.

The presentation covered:

* Challenges of developing a complete solution within a single day.
* Experiences learning and applying AWS technologies under tight deadlines.
* The importance of teamwork and effective communication.
* The value of practical experience beyond competition results.
* Motivation to continuously improve technical knowledge and professional skills.

### Adaptive AML Workflow Engine

The Six Pillars Team introduced an AI-powered Anti-Money Laundering (AML) workflow system.

Main features included:

* Machine Learning models for evaluating suspicious financial transactions.
* AI Agents capable of automatically investigating abnormal activities.
* Decision support for Hold, Dismiss, or Escalate actions.
* Amazon Bedrock Agent coordinating multiple AI agents.
* Guardrails and cross-validation mechanisms to reduce AI hallucinations.
* Security implemented using AWS IAM, AWS KMS, and AWS Secrets Manager.
