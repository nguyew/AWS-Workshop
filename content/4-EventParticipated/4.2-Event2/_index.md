# Event Report: Saturday Meet Up

## Event Objectives

* Share practical knowledge and real-world experiences in AWS, Cloud Computing, DevOps, and Artificial Intelligence.
* Help students become familiar with modern technologies widely adopted in the IT industry.
* Showcase practical projects developed using AWS services.
* Provide career guidance in Cloud Computing, System Administration, Cyber Security, and AI.
* Encourage networking, knowledge sharing, and participation in the technology community.

## Speakers

* **Nguyen Quoc Bao**
* **Huynh Quoc Bao**
* **Viet Phat**
* **Le Hoang Gia Dai**
* **Tran Trung Vinh**

## Main Sessions

### Multiplayer in the Cloud – Connecting Godot Clients with AWS WebSockets

Nguyen Quoc Bao demonstrated how multiplayer game systems can be implemented on AWS by utilizing WebSocket, AWS Lambda, and DynamoDB.

#### Main Highlights

* Comparison of different multiplayer communication models, including UDP, WebSocket, and HTTP Polling.
* Designing real-time matchmaking and communication services with AWS WebSocket.
* Integrating the Godot game engine with AWS cloud services.
* Introducing AWS GameLift for developing scalable multiplayer games.

### Docker – Modern Containerization Technology

Huynh Quoc Bao presented an overview of Docker and container-based application deployment.

#### Main Highlights

* Understanding virtualization and the drawbacks of traditional virtual machines.
* Learning the fundamentals of containers and Docker.
* Comparing virtual machines with container technology.
* Exploring the benefits of Docker for software deployment.
* Common Docker applications in CI/CD pipelines, Microservices, and Cloud Computing.

### Building GraphRAG Applications with Amazon Bedrock and Amazon Neptune

Viet Phat introduced GraphRAG and explained how graph databases enhance AI-powered applications.

#### Main Highlights

* Introduction to Retrieval-Augmented Generation (RAG).
* Limitations of traditional RAG when handling multi-step reasoning.
* Using Knowledge Graphs to improve information retrieval through GraphRAG.
* Developing GraphRAG solutions with Amazon Bedrock and Amazon Neptune.
* Comparing AWS managed services with open-source alternatives.

### Machine Learning-Based Network Intrusion Detection on AWS

Le Hoang Gia Dai shared a cybersecurity project that integrates AWS WAF with Machine Learning techniques for attack detection.

#### Main Highlights

* Overview of AWS WAF and the limitations of rule-based protection.
* Introduction to Network Intrusion Detection Systems (NIDS).
* Training machine learning models using the CSE-CIC-IDS2018 dataset.
* Deploying the solution on AWS with a real-time monitoring dashboard.
* Combining AWS WAF and Machine Learning to improve threat detection accuracy.

### From IT Helpdesk to Senior System Administrator

Tran Trung Vinh shared his professional journey from IT Helpdesk to System Administrator before moving toward Cloud Computing and DevOps.

#### Main Highlights

* Essential skills developed while working in IT Helpdesk.
* Learning Linux and Networking as the foundation for becoming a System Administrator.
* Daily responsibilities and practical experiences of a Sysadmin.
* A recommended learning roadmap for Cloud and DevOps careers.
* Interview experiences and career development advice.
