### Week 6 Objectives:

* Develop a strong foundation in database systems and core database concepts.
* Explore the characteristics and differences between relational and non-relational database models.
* Understand transactional and analytical database processing methods.
* Study AWS database solutions and identify appropriate services for different workloads.
* Gain practical experience with Amazon RDS, including database deployment, connectivity, backup, and recovery.
* Learn the end-to-end process of migrating Oracle databases to Amazon Aurora PostgreSQL.

### Week 6 Achievements:

* **Summary:**
  * During this week, I strengthened my understanding of database technologies and AWS database services. Through theoretical study and practical exercises, I learned how to deploy, manage, protect, and migrate databases on AWS while gaining insight into selecting suitable database solutions for different application requirements.

* **Theory learned:**
  * Built a solid understanding of database fundamentals, including Sessions, Indexes, Partitions, Transaction Logs, Buffers, and Execution Plans.
  * Compared relational database systems (RDBMS) with NoSQL databases and explored common NoSQL models such as Document, Key-Value, Wide-Column, and Graph databases.
  * Studied OLTP and OLAP processing models, along with the role of Data Warehouses in analytical workloads.
  * Explored Amazon RDS architecture and key features, including Read Replicas, Multi-AZ deployments, Automatic Failover, Storage Auto Scaling, and encryption.
  * Learned the architecture and advanced capabilities of Amazon Aurora, including Backtrack, Cloning, Global Database, and Multi-Master deployment.
  * Gained knowledge of Amazon ElastiCache for caching and Amazon Redshift for large-scale data analytics.
  * Understood the database migration workflow from Oracle to Amazon Aurora PostgreSQL using AWS migration tools.

* **Hands-on labs:**
  * Created and configured Amazon RDS database instances.
  * Connected applications to Amazon RDS and Amazon Aurora databases.
  * Performed database backup, restoration, and recovery testing.
  * Completed schema conversion from Oracle to Aurora PostgreSQL.
  * Migrated database data to AWS and verified migration results.
  * Practiced selecting appropriate AWS database services based on different workload requirements.
