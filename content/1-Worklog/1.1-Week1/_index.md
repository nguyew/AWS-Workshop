### Week 1 Achievements:

* Develop a solid understanding of cloud computing principles and how AWS supports cloud infrastructure deployment and management.
  
* Explore the core categories of AWS services, including:
  
  * Compute
  * Storage
  * Networking
  * Database
  * Security and Management

* Engage with members of the FCAJ community to exchange knowledge, discuss technical topics, and enhance learning through collaboration.

* Create and configure an AWS Free Tier account while gaining awareness of Free Tier benefits, limitations, and best practices for cost control.

* Become comfortable using the AWS Management Console by:

  * Navigating AWS services efficiently
  * Creating and managing basic cloud resources
  * Checking the operational status of AWS services

* Install and configure the AWS Command Line Interface (AWS CLI), including:
  
  * Setting up access credentials
  * Configuring the default AWS Region
  * Validating the connection between the local environment and the AWS account

* Practice essential AWS CLI commands to:
  * Verify CLI configuration
  * Retrieve available AWS Regions
  * Interact with commonly used AWS services
  * Manage key pairs and other fundamental resources

* Learn how to use AWS Budgets for effective cost management by:

  * Monitoring AWS spending
  * Configuring budget notifications
  * Preventing unexpected charges through proactive budgeting

* Understand the fundamentals of AWS Identity and Access Management (IAM), including:

  * Creating and managing IAM users and groups
  * Assigning permissions using IAM policies
  * Applying security best practices for account access control

* Build confidence in using both the AWS Management Console and AWS CLI together to manage AWS resources more efficiently during hands-on exercises.
